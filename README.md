# Jogo

Jogo multiplayer de extração com magia, em 3D e em primeira pessoa. Os jogadores entram numa masmorra, coletam itens e tentam sair com o saque.

## Decisões

- Cada classe tem três habilidades próprias.
- As armas são varinhas, cetros e grimórios.
- Cada arma define um ataque básico e uma habilidade. Trocar de arma troca essas duas ações e preserva as habilidades da classe.
